# RESPIRA QUIZ

呼吸器の医学英単語28語を学ぶ、スマートフォン対応の四択クイズです。

## 使い方

英語→日本語／日本語→英語を選んでスタート。全28問をランダム出題し、回答後すぐに正誤と覚え方を表示します。終了後は間違えた単語だけを復習できます。

## 公開とプライバシー

HTML・CSS・JavaScriptだけで動作します。GitHub Pagesの公開元は `main` ブランチの `/ (root)` です。

個人情報・プリント画像・広告・解析ツール・外部ライブラリは含みません。回答は保存・送信されず、再読み込みでリセットされます。ホスティングサービスのアクセス記録は、そのサービスの取り扱いに従います。

医学用語の暗記用です。診断・治療の判断には使用しないでください。
